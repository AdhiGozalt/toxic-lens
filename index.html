  1. Clean the text

  2. Translate slang

    Informal spellings become standard words, so the model sees "tidak" whether someone typed "gak" or "ga".

  3. Split into words

    Click a word to remove it and watch the whole calculation change.

  4. Look up the vocabulary

    Only words and two-word phrases the model learned can affect the score.

  5. Weigh each term with TF-IDF

    Rare terms count for more. Multiplying each weight by what the model learned gives the term's contribution.

  7. Compute the final score

    The contributions are added to the model's starting point, and the sigmoid function turns that total into a percentage.

What to keep in mind

  • This is a simplified, explainable model. It is not the C-RNN from the published paper, and it was trained on a different dataset.
  • The tweets are mostly political, so ordinary political language can score too high.
  • It reads words, not intent. Sarcasm, quotation and context are invisible to it.
  • Use it to learn how text classification works, not to judge or moderate real people.
